# Pickaxe Memory OS Spec

Status: Future / Planned. Documentation only.

## Purpose

Memory OS preserves source context, decisions, outcomes, mistakes, rules, prompts, and company continuity so Pickaxe improves without pretending to learn autonomously.

## Core Modules

- Archive
- Learning Ledger
- Source lineage
- Decision history
- Rule registry
- Prompt Engine archive
- Codex prompt improvements
- Daily System Improvement
- Performance Tracker

## Institutional Prompt Engine Memory Loop

Motto: **Raw idea in. Institutional output out.**

Every rough CEO B idea should become a memory object when it changes the operating system, product architecture, research rules, source standards, or future prompt quality.

```text
Raw Thought
  -> Clarify Intent
  -> Upgrade Prompt
  -> Apply Institutional Quality Gate
  -> Produce Output
  -> Define Next Action
  -> Archive Lesson
  -> Improve Next Prompt
```

### Prompt Archive Record

Every archived prompt improvement should record:

- raw CEO B input
- interpreted objective
- upgraded institutional prompt
- target page, feature, agent, workflow, or decision
- quality gates applied
- mini-gates applied
- output produced
- risk/disclosure boundaries preserved
- next action defined
- lesson learned
- affected documentation or product area
- CEO B decision state
- effective date

### Memory Rule

Memory OS stores prompt improvements, lessons, and proposed rule changes. It does not approve its own recommendations, self-modify runtime behavior, create fake live agents, or bypass CEO B.

## Performance Tracker

Aliases: P&L Calendar, Trading Performance Dashboard, Learning Ledger Performance View, CEO B Performance OS.

- Owner: Archive + Learning Ledger
- Future route: `#/performance`
- Connected systems: Options Alerts, Quant Lab, Memory OS, Mission Control
- Status: Future / Planned

### Purpose

Track CEO B's private trading and research performance over time so reviewed packets, outcomes, mistakes, seasonality, streaks, drawdowns, and lessons become measurable.

### Required Views

- Year Calendar Grid
- Executive Summary
- Year-by-Year Comparison
- Top 5 Best Months
- Top 5 Worst Months
- Month Seasonality
- Streaks / Quarter Stats / Insights
- Alpha Notes
- Rule Break Tracker
- Options Contract Quality Summary
- Volatility Context Summary
- CEO B Review Compliance

### Metrics

- net P&L
- gross gains
- gross losses
- win rate
- profit factor
- expectancy
- average win
- average loss
- gain/loss ratio
- active months
- winning months
- losing months
- monthly volatility
- max drawdown
- best month
- worst month
- best trade
- worst trade
- rule breaks
- CEO B reviewed percentage

### Safety

- private analytics only
- research and education only
- no public performance claims
- no guaranteed returns
- no broker execution
- no broker account sync
- no copy-trading
- no fake live data
- no public leaderboard
- CEO B final review required

Do not implement until Options Alerts, Risk Desk, CEO B Review Gate, and Archive Outcome are stable.
