# Blueprint Drawing Checklist

Purpose: help B draw the 20-section Pickaxe Capital / AI Habitat OS before the next implementation sprint.

## What To Draw First

Start with three anchors:

- CEO B in the center or command layer.
- Mission Control as the overview cockpit.
- Source Hub as the trust/intelligence layer.

Then add:

- Watchlists as the Research Universe.
- Archive as saved intelligence memory.
- Obsidian as private memory outside the public website.
- Agents as placeholder/future operators, not live workers.

## Route Grouping Checklist

Label each section as one of:

- Core
- Research
- System
- Future

Suggested grouping:

- Core: Mission Control, Alerts, Source Hub, Archive, Watchlists, Risk.
- Research: Signals, Trend Radar, Bookmarks, Learning Ledger, Research Desk.
- System: Staging, Vision Map, Habitat OS, Command Console, Roadmap.
- Future: Agents rebuild, Markets, Options, Catalysts, Money Lab expansion.

## Mission Control Module Checklist

Draw what CEO B should see first:

- Command header.
- Market/research regime summary.
- Source gaps.
- Alerts requiring review.
- Watchlist pulse.
- Archive memory preview.
- Risk Desk boundary.
- Next manual mission.

Do not draw:

- Fake live market data.
- Fake P&L.
- Trade execution controls.
- Broker connection states.

## Source Hub Connection Checklist

Show how source candidates move:

```text
Sources -> Source Hub -> Watchlists / Signals / Alerts / Archive / Dashboard -> CEO B
```

Label:

- Source type.
- Trust label.
- Route owner.
- Private/public status.
- CEO B review gate.
- Source-required blockers.

## Archive Memory Checklist

Draw Archive as:

- Cleaned research memory.
- Source-origin library.
- Review history.
- Lesson candidates.
- Saved thesis/context notes.
- Archive-to-Learning Ledger path.

Avoid:

- Raw Obsidian note dumping.
- Raw bookmark export dumping.
- Private URL publication.

## Obsidian / Private Memory Checklist

Draw Obsidian outside the public website.

Label:

- Private vault.
- Sketches.
- Strategy notes.
- Session logs.
- Raw bookmarks or messy thinking.
- Local `/ai-handoff` and `/source-hub-staging` summaries.

Boundary:

- Only sanitized handoff summaries should inform Codex/ChatGPT.
- Raw vault contents should not be published into `public/`.

## Agents Placeholder / Future Checklist

Draw Agents as future ownership lanes, not live execution.

Possible lanes:

- Archivist: source memory and archive hygiene.
- Forge: briefs and thesis cards.
- Sentry: alert review.
- Oracle: research signal interpretation.
- Scout: discovery.
- Risk Desk: escalation blocker.
- CEO B: final decision layer.

Label clearly:

- Planned.
- Local-only.
- Manual review.
- No live telemetry.
- No autonomous jobs.

- Broker/execution controls.
