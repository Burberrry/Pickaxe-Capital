# Phase 1.5 - Foundational Truth Cleanup

## Why This Phase Existed

Phase 1 found conflicts between the public static/demo product truth and development/runtime behavior. Phase 1.5 resolves those conflicts before visual Phase 2 work.

## Scope

- Disable live external services by default in the local development server.
- Publish only the public-safe `public/` artifact to GitHub Pages.
- Relabel execution-like public language as research review language.
- Preserve LocalStorage compatibility through normalization.
- Document the effective render paths.
- Add checks for mirrors, safety language, deployment boundary, and routes.
- Reconcile project status and next-step documentation.

## Preserved

Static-first HTML/CSS/JavaScript, hash routing, LocalStorage state, existing routes, current working pages, root/public mirrors, demo data, GitHub Pages deployment, and human-reviewed research positioning.

## Not Included

No hero redesign, Alerts Desk redesign, Agents build, AI Habitat OS build, backend migration, live API integration, broker execution, auto-trading, copy-trading, or broad refactor.
